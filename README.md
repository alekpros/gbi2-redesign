# Завод ЖБИ-2 — концепт нового сайта

Демонстрационная версия редизайна [gbi2.ru](https://gbi2.ru) для коммерческого предложения.
Данные (каталог, таблицы характеристик, адреса, телефоны, фото) взяты с действующего сайта
и принадлежат АО «Завод ЖБИ-2». Тексты переписаны. Страницы закрыты от индексации (`noindex`).

## Демо

https://alekpros.github.io/gbi2-redesign/ — обновляется автоматически при пуше в `main`.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:4321. Что показать клиенту за 5 минут:

1. Главная: блок «марка как на чертеже», кнопка «Другая марка».
2. Поиск: набрать `фбс2446` → переход к строке ФБС 24.4.6-Т с подсветкой.
3. Нажать «+» в нескольких строках таблиц → счётчик «Заявка» в шапке → страница заявки с количеством.
4. Телефон: режим адаптива в браузере (375 px).
5. Страница «Что изменилось» (ссылка в жёлтой полосе сверху).

Статическая сборка для показа без интернета: `npm run build`, папка `dist/` открывается через `npm run preview`.

## Устройство

- [Astro 5](https://astro.build), статическая сборка, без клиентских фреймворков.
- Шрифты Golos Text и Fira Sans Condensed хранятся локально (`@fontsource`).
- `src/data/catalog.json` — каталог, собранный скриптом `scripts/build_catalog.py` из выгрузки старого сайта.
- `public/marks.json` — индекс 725 марок для поиска.
- `src/data/site.ts` — тексты разделов. Пометка `confirm: true` — данные, которые нужно сверить с заводом.

Адреса страниц каталога совпадают со старым сайтом. Для GitHub Pages сборка идёт с `BASE_PATH=/gbi2-redesign/`.
